# EstateNest — Real Estate Website

A responsive real-estate landing page built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

No build tools or dependencies are required. Internet is needed for the remote Unsplash photos.

## Included features
- Responsive layout for desktop, tablet, and mobile
- Property cards and category filters
- Search by location/name, property type, and maximum budget
- Favourite/save buttons with toast feedback
- Mobile navigation menu
- Accessible labels and image alt text

## Customise
- Edit sample listings in `index.html`.
- Change colours in the `:root` CSS variables.
- Replace the illustrative `hello@estatenest.example` email with your real contact details.

**Note:** Listing details and prices are sample/demo content. This is a front-end template; it does not include a database, authentication, or a working lead-management backend.
